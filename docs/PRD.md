## 1. 專案概述

### 1.1 背景與動機

現代人生活節奏快，常因購買食材後不知如何處理或沒時間烹飪，導致食材過期浪費，而現有的食譜 App 太複雜且外送又貴。同時，單純的食譜 App 往往缺乏互動性，使用者容易下載後便不再使用。

「隨『食』隨地」系統希望透過 AI 辨識與**寵物養成**的遊戲化機制，讓烹飪變得像遊戲一樣有趣，同時達成惜食的目標。

**F-06 寵物進化圖鑑**是寵物養成系統的核心展示功能。當使用者持續烹飪並累積經驗值後，寵物會成長、進化、改變外觀。圖鑑系統讓使用者能收集並回顧所有已解鎖的寵物型態，藉此提升成就感與長期使用動機。

### 1.2 目標用戶

| 用戶類型 | 特徵描述 |
|----------|----------|
| **外宿大學生 / 租屋族** | 預算有限、自炊經驗不足，需要簡單引導且有趣的烹飪動力 |
| **忙碌上班族** | 時間碎片化，希望快速找到食譜並獲得持續使用的激勵 |
| **環保惜食者** | 重視食材利用率，希望透過系統減少浪費，同時享受養成樂趣 |

### 1.3 核心價值主張

- **成就感驅動**：透過寵物進化的視覺回饋，讓使用者每次烹飪都感受到「養成進度」
- **收集樂趣**：圖鑑系統激發「全收集」心理，提升長期黏著度
- **資料永續**：進化與圖鑑狀態持久化儲存，使用者不會因重新整理或換裝置而失去進度

### 2.2 使用者故事

#### F-06-01 寵物進化觸發機制

> 作為一位**使用者**，我希望當我的寵物達到指定等級（如 Lv.5、Lv.10）時，**系統自動觸發進化事件並切換寵物的外觀圖片**，以便我能感受到養成的成就感與寵物的成長。

**驗收條件 (Acceptance Criteria)：**
- [ ] 寵物達到進化等級門檻（Lv.5、Lv.10、Lv.20 等）時，系統自動偵測並觸發進化
- [ ] 進化後寵物外觀圖片自動更新為對應階段的圖片
- [ ] 進化結果寫入資料庫，確保下次載入時維持新外觀
- [ ] 進化門檻可由後端資料表設定，具備擴充性

#### F-06-02 進化事件動畫與通知

> 作為一位**使用者**，我希望寵物進化時能看到**動畫效果與祝賀通知**，以便我獲得即時的正向回饋與驚喜感。

**驗收條件：**
- [ ] 進化觸發時前端播放進化動畫（如光效、寵物變身過渡）
- [ ] 動畫播放完畢後顯示進化結果卡片，包含新外觀、新名稱與等級資訊
- [ ] 使用者可點擊「確認」關閉通知，回到主畫面

#### F-06-03 寵物圖鑑介面

> 作為一位**使用者**，我希望有一個**寵物圖鑑頁面**，能一覽所有寵物型態的縮圖與解鎖狀態，以便我掌握自己的收集進度。

**驗收條件：**
- [ ] 圖鑑頁面以卡片式網格排列顯示所有寵物型態
- [ ] 已解鎖的寵物顯示彩色圖片與名稱
- [ ] 未解鎖的寵物以灰階剪影或問號圖示呈現
- [ ] 顯示收集進度（如「已解鎖 3 / 8」）

#### F-06-04 寵物詳情查看

> 作為一位**使用者**，我希望能點擊圖鑑中的已解鎖寵物，**查看詳細資訊、高解析度圖片與進化歷程**，以便我回顧寵物的成長故事。

**驗收條件：**
- [ ] 點擊已解鎖寵物卡片後，展開或跳轉至詳情頁面
- [ ] 詳情頁面包含：寵物名稱、等級、進化階段、高解析度圖片、風味描述文字
- [ ] 詳情頁面顯示該寵物的進化歷程（從哪一階段進化而來）
- [ ] 點擊未解鎖寵物時，顯示「尚未解鎖」提示與解鎖條件

#### F-06-05 圖鑑解鎖狀態持久化

> 作為一位**使用者**，我希望我的寵物等級與圖鑑解鎖狀態能**永久儲存在伺服器端**，以便我重新整理瀏覽器或更換裝置後，進度不會消失。

**驗收條件：**
- [ ] 寵物等級、當前外觀、已解鎖圖鑑項目皆儲存於 SQLite 資料庫
- [ ] 頁面重新整理後，寵物狀態與圖鑑進度完整還原
- [ ] API 提供讀取與更新介面，供前端呼叫

#### F-06-06 未解鎖寵物遮罩

> 作為一位**使用者**，我希望看到尚未解鎖的寵物以**神秘剪影**呈現，以便激發我的好奇心與繼續烹飪的動力。

**驗收條件：**
- [ ] 未解鎖的寵物型態在圖鑑中顯示為灰階剪影或帶有「？」符號
- [ ] 滑鼠懸停（或手機長按）時顯示解鎖條件提示（如「需要達到 Lv.10」）

#### F-06-07 進化歷程時間軸

> 作為一位**使用者**，我希望能在一條**視覺化時間軸**上，看到我的寵物從最初型態到現在的完整進化歷程，以便我感受到養成的旅程。

**驗收條件：**
- [ ] 時間軸以垂直或水平方式呈現各進化階段節點
- [ ] 每個節點包含：進化時間、等級、外觀縮圖
- [ ] 已完成的節點以彩色呈現，未達成的節點以灰色虛線呈現

## 3. 非功能需求

### 3.1 技術限制

| 項目 | 規格 |
|------|------|
| **後端框架** | Python Flask |
| **模板引擎** | Jinja2 |
| **資料庫** | SQLite |
| **前端** | HTML5 + CSS3 + JavaScript（Vanilla） |
| **靜態資源** | 寵物圖片存放於 `static/images/pets/` |

### 3.2 效能考量

- 圖鑑頁面載入時間應在 **2 秒內**完成（含圖片）
- 寵物圖片應進行適當壓縮，單張不超過 **200KB**
- 進化動畫使用 CSS/JS 實作，不依賴外部動畫庫，以減少載入負擔

### 3.3 安全考量

- 進化觸發邏輯必須在**伺服器端驗證**，防止前端竄改等級資料
- 圖鑑解鎖 API 需驗證使用者身份（依賴系統既有的登入機制）
- 寵物等級更新需檢查合理性（不可跳級、不可負數）

### 3.4 相容性

- 支援主流瀏覽器：Chrome、Firefox、Safari、Edge 最新兩個版本
- 支援手機與桌面裝置的響應式版面

## 4. 寵物進化階段設計

以下為預設的寵物進化階段定義（可根據團隊需求調整）：

| 階段 | 等級門檻 | 外觀代稱 | 圖片檔名範例 | 描述 |
|------|----------|----------|-------------|------|
| Stage 1 | Lv.1（初始） | 蛋 / 幼體 | `pet_stage1.png` | 初始狀態，剛孵化的小寵物 |
| Stage 2 | Lv.5 | 幼年體 | `pet_stage2.png` | 成長中的寵物，外觀略有變化 |
| Stage 3 | Lv.10 | 成長體 | `pet_stage3.png` | 明顯成長，外觀更豐富 |
| Stage 4 | Lv.20 | 成熟體 | `pet_stage4.png` | 完全體，外觀華麗 |
| Stage 5 | Lv.30 | 究極體 | `pet_stage5.png` | 最終進化，獨特造型與特效 |

> **備註**：進化階段數量與等級門檻可透過資料庫設定調整，無需改動程式碼。

## 6. 系統互動關係

本功能（F-06）與系統其他功能的互動關係如下：

```
┌─────────────────────────────────────────────────────┐
│                  隨「食」隨地 系統                      │
│                                                     │
│  ┌───────────┐    經驗值     ┌───────────────────┐  │
│  │ 烹飪完成   │ ──────────▶ │  寵物等級系統       │  │
│  │ (其他功能) │             │  (升級 / 進化判定)  │  │
│  └───────────┘             └────────┬────────────┘  │
│                                     │               │
│                              達到進化門檻            │
│                                     │               │
│                                     ▼               │
│                            ┌────────────────┐       │
│                            │  F-06 寵物進化   │       │
│                            │  圖鑑系統        │       │
│                            └────────┬───────┘       │
│                                     │               │
│                          ┌──────────┴──────────┐    │
│                          ▼                     ▼    │
│                   ┌────────────┐       ┌──────────┐ │
│                   │ 進化動畫/  │       │ 寵物圖鑑  │ │
│                   │ 通知       │       │ 頁面      │ │
│                   └────────────┘       └──────────┘ │
└─────────────────────────────────────────────────────┘
```

**前置依賴：**
- 需要系統的**使用者登入/驗證機制**（取得 `user_id`）
- 需要**寵物基礎資料**（寵物的初始建立，可能屬於其他功能模組）
- 需要**經驗值 / 等級系統**的介面（其他功能完成烹飪任務後呼叫升級 API）

**本功能輸出：**
- 提供寵物當前外觀資訊的 API（供主畫面顯示用）
- 提供圖鑑頁面路由（供導航列連結）

## 7. 頁面與 API 規劃（概要）

### 7.1 頁面路由

| 路由 | 方法 | 說明 |
|------|------|------|
| `/collection` | GET | 寵物圖鑑主頁面，顯示所有寵物型態卡片 |
| `/collection/<int:pet_stage_id>` | GET | 寵物詳情頁面，顯示特定型態的完整資訊 |

### 7.2 API 端點

| 端點 | 方法 | 說明 |
|------|------|------|
| `/api/pet/status` | GET | 取得當前使用者的寵物狀態（等級、外觀、經驗值） |
| `/api/pet/evolve` | POST | 觸發進化檢查（由其他功能的升級流程呼叫） |
| `/api/collection` | GET | 取得使用者的圖鑑解鎖資料 |
| `/api/collection/<int:pet_stage_id>` | GET | 取得特定寵物型態的詳細資訊 |

## 附錄：名詞定義

| 名詞 | 定義 |
|------|------|
| **寵物 (Pet)** | 使用者在系統中飼養的虛擬角色，會隨著烹飪活動成長 |
| **進化 (Evolution)** | 寵物達到特定等級門檻後，外觀與階段的自動升級 |

| **等級門檻 (Level Threshold)** | 觸發進化所需的最低等級 |
