# 隨食隨地 - 功能需求文件 (PRD)

## 1. 專案與功能概述
- **專案名稱**：隨食隨地
- **專案描述**：現代人生活節奏快，常因購買食材後不知如何處理或沒時間烹飪，導致食材過期浪費，而現有的食譜App太複雜且外送又貴。同時，單純的食譜 App 往往缺乏互動性，使用者容易下載後便不再使用。我們希望透過「隨『食』隨地」結合 AI 辨識與寵物養成，讓烹飪變得像遊戲一樣有趣，同時達成惜食的目標。
- **目標用戶**：
  - **外宿大學生/租屋族**：預算有限且廚房設備簡單，希望用現有食材快速出餐。
  - **忙碌上班族**：下班後沒靈感思考菜單。
  - **環保惜食者**：希望能有效利用剩餘食材，減少廚餘。
- **核心價值主張**：將烹飪與惜食結合寵物養成遊戲，提升使用者的黏著度，讓清空冰箱變成一場有趣的互動體驗。

## 2. 功能需求：F-03 虛擬寵物養成系統
- **功能名稱**：虛擬寵物養成系統
- **功能編號**：F-03
- **功能描述**：系統需有一個專屬頁面顯示虛擬寵物。包含經驗值（EXP）、等級（Level）與成長進度條，數值需與資料庫同步，隨餵食行為動態更新。

### 使用者故事 (User Stories)
1. **作為** 一名使用者，**我希望** 能夠在專屬頁面看到我的虛擬寵物及其當前狀態（如等級、經驗值進度條），**以便** 了解寵物的成長進度。
2. **作為** 一名使用者，**我希望** 每次完成「餵食」（如完成一道料理並記錄）後，寵物能獲得對應的經驗值（EXP），**以便** 獲得成就感與遊戲互動感。
3. **作為** 一名使用者，**我希望** 經驗值進度條能動態更新並在經驗值達標時升級（Level Up），**以便** 持續有動力參與料理任務。
4. **作為** 一名使用者，**我希望** 寵物的數值（等級與經驗值）能與資料庫同步保存，**以便** 我在不同裝置或下次登入時能接續養成進度。
5. **作為** 系統管理員，**我希望** 能夠設定不同行為獲得的經驗值參數與升級所需的經驗值門檻，**以便** 調整遊戲平衡性。

## 3. 非功能需求
- **技術限制**：
  - 後端：Python + Flask
  - 模板引擎：Jinja2
  - 資料庫：SQLite (紀錄 User ID、Pet ID、Level、Current EXP 等關聯資料)
  - 前端：HTML/CSS/JavaScript (需包含動態進度條更新的簡易動畫效果)
- **效能與安全考量**：
  - 每次餵食行為觸發的資料庫更新需確保一致性，避免重複計算經驗值。
  - 經驗值的計算與驗證需在後端進行，防止使用者透過前端竄改數值。
  - 頁面加載速度需優化，寵物圖片或動畫資源需快取以提升使用者體驗。

## 4. MVP 範圍 (Minimum Viable Product)
- **Must Have (必須有)**：
  - 專屬的虛擬寵物展示頁面（靜態圖片即可）。
  - 顯示當前等級 (Level) 與經驗值 (EXP) 數值。
  - 視覺化的經驗值成長進度條。
  - 後端能接收「餵食」請求並更新 SQLite 中的 EXP，且進度條能根據最新數值渲染。
- **Should Have (應該有)**：
  - 經驗值增加時的簡易前端動畫（如進度條增加的過場動畫）。
  - 升級時的通知或提示效果（如「恭喜升級！」的彈出視窗）。
- **Nice to Have (可以有)**：
  - 寵物根據不同等級有不同的外觀變化。
  - 與寵物的簡單互動（例如點擊寵物會有反應或發出聲音）。
