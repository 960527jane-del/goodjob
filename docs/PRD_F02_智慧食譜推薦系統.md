# PRD - 智慧食譜推薦系統 (功能編號：F-02)

## 1. 專案概述

### 背景與動機
現代人生活節奏快，常因購買食材後不知如何處理或沒時間烹飪，導致食材過期浪費，而現有的食譜 App 太複雜且外送又貴。同時，單純的食譜 App 往往缺乏互動性，使用者容易下載後便不再使用。我們希望透過「隨『食』隨地」結合 AI 辨識與寵物養成，讓烹飪變得像遊戲一樣有趣，同時達成惜食的目標。本功能「智慧食譜推薦系統（F-02）」專注於解決「現有食材如何應用」的核心痛點。

### 目標用戶
- **外宿大學生/租屋族**：預算有限且廚房設備簡單，希望用現有食材快速出餐。
- **忙碌上班族**：下班後沒靈感思考菜單，需要快速、直接的烹飪建議。
- **環保惜食者**：希望能有效利用剩餘食材，減少廚餘與浪費。

### 核心價值主張
讓使用者不再為「冰箱裡剩這些能煮什麼」而苦惱，系統自動根據「我的材料庫」庫存食材推薦實用、簡單的食譜，降低烹飪門檻，促進食材的完全利用，並成為與寵物養成系統互動的橋樑。

---

## 2. 功能需求

### 主要功能列表
1. **F-02.1 整合我的材料庫**：系統需能自動讀取使用者目前在「我的材料庫」中記錄的所有可用食材。
2. **F-02.2 外部食譜 API 請求與篩選**：將現有食材作為關鍵字或篩選參數，向外部食譜 API 發送請求，並篩選出能最大化利用現有食材的食譜結果。
3. **F-02.3 推薦食譜列表展示**：展示符合條件的食譜清單，列表中須清楚顯示食譜名稱、縮圖、預估烹飪時間，以及所需補足的額外配料。
4. **F-02.4 食譜詳細步驟檢視**：使用者點擊特定食譜後，進入詳細頁面查看烹飪步驟、完整的食材比例與營養資訊。
5. **F-02.5 缺漏食材提示**：系統需比對食譜所需配料與現有庫存，清楚標示缺少的食材，方便使用者評估是否採買或替換。

### 使用者故事 (User Stories)
- **作為 外宿大學生/租屋族**，我希望 **系統能推薦使用現有食材的簡易食譜**，以便 **我能在預算內快速完成料理，不需額外購買太多調味料或複雜食材**。
- **作為 忙碌上班族**，我希望 **能在食譜推薦列表直接看到烹飪所需的時間**，以便 **我能挑選符合今晚精力的快速料理**。
- **作為 環保惜食者**，我希望 **系統推薦的食譜能優先消耗「我的材料庫」中即將過期的食材**，以便 **有效減少食物浪費**。
- **作為 系統使用者**，我希望 **點開食譜後能看到清楚的步驟教學**，以便 **我不具備豐富廚藝也能順利跟著煮**。
- **作為 系統使用者**，我希望 **系統能告訴我為了做這道菜還缺了哪些配料**，以便 **我在回家的路上可以順便去超市補齊**。

## 3. 非功能需求

### 技術限制
- **前後端框架**：依據專案現有技術棧開發（如 Flask + Jinja2 + SQLite）。
- **外部 API 依賴**：需串接穩定的第三方食譜 API（如 Spoonacular, Edamam 等），開發時需考慮 API 的 Rate Limit 與免費額度限制。

### 效能與安全考量
- **API 回應延遲 (Latency)**：因依賴外部 API，需實作前端的 Loading 狀態（如 Skeleton Loading 或 Spinner），優化等待體驗。
- **快取機制 (Caching)**：針對常見的食材組合搜尋結果，可考慮在伺服器端做短暫快取，減少外部 API 呼叫次數並加快回應速度。
- **錯誤處理 (Error Handling)**：當外部 API 暫時無法連線，或是回傳「查無相符食譜」時，需有友善的 Fallback 介面（例如提供預設的基礎百搭食譜，或引導使用者更換食材關鍵字）。

## 4. MVP 範圍

### Must Have (必須具備 - 第一階段核心)
- 成功讀取「我的材料庫」食材資料。
- 成功串接一款外部食譜 API，並以現有食材做為關鍵字取得搜尋結果。
- 顯示推薦食譜列表（包含食譜名稱、縮圖、烹飪時間）。
- 顯示單一食譜的詳細頁面（包含所需配料、詳細烹飪步驟）。

### Should Have (應該具備 - 提升體驗)
- 缺漏食材對比提示：在列表中標示出「目前擁有食材比例 (例如: 3/5)」或「尚缺：雞蛋、青蔥」。
- 依照「即將過期食材」優先推薦食譜的排序邏輯。
- 等待 API 回應時的 Loading 畫面設計。

### Nice to Have (最好具備 - 未來擴充)
- 將缺漏的食材一鍵加入「購物車 / 採買清單」。
- 結合寵物養成系統：烹飪完成/採納食譜後，可獲得虛擬點數或寵物經驗值。
- 根據使用者的飲食偏好（如素食、不吃辣、過敏原）過濾 API 結果。
