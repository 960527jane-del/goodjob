# PRD - 虛擬寵物養成系統 (F-03)

## 1. 專案與功能概述

### 專案名稱
隨食隨地

### 專案描述
現代人生活節奏快，常因購買食材後不知如何處理或沒時間烹飪，導致食材過期浪費，而現有的食譜 App 太複雜且外送又貴。同時，單純的食譜 App 往往缺乏互動性，使用者容易下載後便不再使用。我們希望透過「隨『食』隨地」結合 AI 辨識與寵物養成，讓烹飪變得像遊戲一樣有趣，同時達成惜食的目標。

### 功能背景與動機
單純的食譜與食材管理應用難以維持使用者的長期黏著度。為了解決這個問題，導入「虛擬寵物養成系統（F-03）」，透過遊戲化的機制，將使用者的烹飪與惜食行為（如：紀錄食材、完成食譜等）轉化為寵物的成長動力（經驗值與升級），藉此激勵使用者持續使用本應用，養成減少食物浪費的好習慣。

### 目標用戶
- **外宿大學生/租屋族**：預算有限且廚房設備簡單，希望用現有食材快速出餐。
- **忙碌上班族**：下班後沒靈感思考菜單。
- **環保惜食者**：希望能有效利用剩餘食材，減少廚餘。

### 核心價值主張
讓烹飪與惜食變得像遊戲一樣有趣，透過虛擬寵物的陪伴與成長，提升使用者管理食材與下廚的動力與成就感。

## 2. 功能需求

以下為「虛擬寵物養成系統 (F-03)」的主要功能需求清單：

1. **寵物專屬展示頁面**
   - **使用者故事**：作為一名使用者，我希望有一個專屬的頁面來查看我的虛擬寵物，以便了解寵物目前的狀態與外貌。

2. **經驗值（EXP）與等級（Level）顯示**
   - **使用者故事**：作為一名使用者，我希望在寵物頁面上能清楚看到目前的等級與經驗值，以便知道還差多少可以升級。

3. **成長進度條**
   - **使用者故事**：作為一名使用者，我希望有一個視覺化的進度條來顯示經驗值成長，以便直觀地感受到我的努力成果。

4. **餵食/互動行為更新**
   - **使用者故事**：作為一名使用者，我希望當我完成特定行為（如：使用快過期的食材烹飪、登入、餵食）後，寵物能即時獲得經驗值，以便立即獲得正向回饋。

5. **資料庫同步機制**
   - **使用者故事**：作為一名系統管理者，我希望寵物的經驗值與等級資料能與後端資料庫（SQLite）即時同步，以便確保使用者的進度在下次登入時不會遺失。

---

## 3. 非功能需求

- **技術限制**：
  - 後端需使用 **Flask** 框架。
  - 前端模板需使用 **Jinja2** 搭配 HTML/CSS/JS 進行渲染。
  - 資料庫需使用 **SQLite** 儲存寵物的狀態資料。
- **效能考量**：
  - 寵物頁面載入時間需小於 2 秒。
  - 經驗值更新與進度條動畫需平滑順暢，不卡頓。
- **UI/UX 考量**：
  - 介面設計需符合年輕、活潑的遊戲化風格。
  - 需支援響應式網頁設計（RWD），確保在手機版與網頁版皆能正常瀏覽。

## 4. MVP 範圍

| 功能項目 | 優先級 | 說明 |
| :--- | :---: | :--- |
| 寵物基本展示頁面 | **Must Have** | 靜態顯示一隻虛擬寵物圖片。 |
| 等級與經驗值文字顯示 | **Must Have** | 從資料庫讀取並顯示 User 對應的寵物 Level 與 EXP。 |
| 視覺化成長進度條 | **Must Have** | 依據 (目前經驗值 / 升級所需經驗值) 比例渲染長度。 |
| 手動觸發餵食（測試用） | **Must Have** | 提供一個按鈕，點擊後增加經驗值並同步至資料庫。 |
| 寵物升級外觀變化 | **Should Have** | 當等級到達特定門檻時，寵物的圖片或狀態會發生改變。 |
| 餵食互動微動畫 | **Nice to Have** | 點擊餵食或升級時，畫面上出現煙火或特效。 |
